# prepare_transform_code

Универсальный разбор комплекта поставки: Excel/PDF → черновик лотов → склейка. Не привязан к имени отправителя и не к профилю выхода.

## Что делает

1. Читает все файлы комплекта (инвойс, пакинг, спецификация, справочник).
2. Находит шапку по подписям колонок, тело до `TOTAL` / `ИТОГО`.
3. Склеивает лоты по правилам из field-anchors (артикул, название+qty, конфликты весов).
4. Отдаёт черновик в вердикт модели (`verdict.py`); модель может поправить поля по исходным файлам, но не выдумывает числа.

## Профили выхода

Профиль задаёт только форму Excel на выходе (18233 / Beijing / TSD). Чтение и склейка одни.

## Тесты

```powershell
python -m unittest prepare_transform_code.tests.test_shipments
```

Часть проверок читает локальные папки `documents_final/` и `documents/` (в git их нет). Без этих папок соответствующие тесты пропускаются или падают — для CI кладите свои фикстуры локально.

## Модули

| Файл | Роль |
|------|------|
| `shipment.py` | точка входа `analyze` |
| `exceldoc.py` / `pdfdoc.py` | чтение листов и PDF |
| `fields.py` / `lines.py` | шапка и строки |
| `join.py` | склейка лотов |
| `verdict.py` | промпт и разбор ответа модели |
| `photos.py` | кадры для локального разбора (папка `prepare_photo/` локально) |
