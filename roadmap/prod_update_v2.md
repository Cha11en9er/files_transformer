# prod_update_v2

## Сделано

### Модель без JPEG (окт 2026)
- Боевой путь: `analyze` → папка `MODEL_INPUTS_ROOT/postavka_{uuid}/` → полный вердикт OpenCode по исходным файлам → `apply_verdict` → export.
- JPEG-тайлы Excel/PDF для модели убраны из сайта (`collect_vision_images` / stash vision в потоке create больше не зовутся).
- В OpenCode включён tool `read`; PDF и сканы можно вложить как file parts; xls/xlsx только путём на диске (base64 xlsx провайдер отвергал).
- Модель вызывается всегда. `ALLOW_SKIP_MODEL=1` - старый known-skip только для отладки.
- `VERDICT_PROMPT=full` по умолчанию. Текст правил про файлы, не про фото. В промпте блок `ФАЙЛЫ НА ДИСКЕ`.
- Env: `MODEL_INPUTS_ROOT`, `MODEL_INPUTS_TTL_H`, `ALLOW_SKIP_MODEL`, `VERDICT_PROMPT`.
- UI-граф: узел «Файлы» вместо «Фото»; прогресс `stage=files`.
- Папки `postavka_*` удаляются после ответа модели и чистятся по TTL.
- Модуль: `backend/app/services/model_inputs.py`. Корень по умолчанию локально `backend/data/model_inputs`.

### Приоритет модели над черновиком кода
- Код по-прежнему читает поставку и даёт черновик в промпт (колонки, шапка, лоты).
- Правила вердикта усилены: источник истины - файлы; черновик - слабая подсказка структуры; при расхождении всегда файл; нельзя массово keep без сверки с файлом.
- Если модель ответила ok - в таблицу идёт её вердикт. Если модель упала - остаётся черновик кода (запасной выход).

### Просмотр «как в Excel»
- Рядом с «Сохранить» в реквизитах кнопка «Посмотреть как в Excel» / «Обычный вид».
- Excel-вид: тот же JSON, что `/export/preview` (те же книги/листы/столбцы, что у скачиваемого ZIP).
- Обычный вид: таблица позиций с ошибками, предупреждениями, вкладками ролей.
- Переключение на всех ширинах экрана (desktop / tablet / phone).

### Маршрут и устойчивость (раньше в этой ветке)
- Сверка сумм строк с итогом листа: диагностика `known` / `similar` / `unknown` (на проде не отключает модель без `ALLOW_SKIP_MODEL`).
- Книга `ПРОВЕРКА.xlsx` в выгрузке.
- Лимиты размера загрузки, пульс прогресса раз в 12 с.

## Как смотреть
- Ветка: `prod_update_v2`
- Порт: 8200, каталог `/opt/files_transformer_update`, unit `excel-transformer-update`
- Один раз: `mkdir -p /opt/files_transformer_update/data/model_inputs`
- В `.env`: `MODEL_INPUTS_ROOT=/opt/files_transformer_update/data/model_inputs`, `ALLOW_SKIP_MODEL=0`, `VERDICT_PROMPT=full`, `OPENCODE_TIMEOUT_S=0` (ждать ответ)
- Known + только Excel: компактный быстрый промпт (сверка шапки и 2-3 строк), не полный трактат. Модель дожидаемся.
- Граф: шапка → строки → склейка → сверка; у модели фазы «открывает файлы / шапка / пакинг / строки». Под «Файлы» - число. Клик «Чтение» - черновик кода.
